# utils/ — pure helpers

- `queryRender.js` — placeholder substitution
- `selection.js` — multi-select helpers
- `pocSummary.js` — notable PoC summary
- `codeSections.js` — code-review section focus helpers

Loaded by `index.modular.html` before components.
