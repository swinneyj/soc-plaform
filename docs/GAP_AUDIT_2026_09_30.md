# Project Gap Audit — full-sweep findings

*Sept 30, 2026. A whole-project sweep for gaps and issues **beyond** the
execution roadmap, plus the consolidated remaining-work list. Read-only
audit; every finding carries evidence, impact, and a remedy.*

## Methodology (what was checked)

Tracked-file inventory vs `.gitignore`; secret-pattern scan (`git grep` for
URL-embedded credentials, API-key/token shapes, key files); local-artifact
tracking check (venvs, caches, Data/Reports); root vs `scripts/attic`
drift; docs/ inventory vs reality; CI workflows; Docker/compose stack;
`.env.example` currency; repo-meta files (LICENSE/SECURITY/CODEOWNERS);
`pytest.ini`; dev-plan factual claims spot-checked against disk.

## Verified clean

- **No secrets tracked.** Every credential-pattern hit is a placeholder
  (localhost URLs, `<user>:<password>` forms) in `.env.example`, README,
  RUNBOOK, `docs/SETUP.md`, `docs/CHAT_HANDOFF.md`. No `.env`, no
  `local-backups/`, no `Data/`, no key files in Git. `neon.tech` appears
  only where expected (AGENTS.md, tracker, `scripts/start`).
- **No tracked junk.** Venvs, `__pycache__`, `.pytest_cache`, binaries:
  all clean after the B2 sweep.
- **`.python-version` absence is deliberate** (`09a53e5` — the pin broke
  Vercel builds). Minor prose staleness remains where older docs cite it.
- **`web/index.html` is live** (redirect shim), not dead code.
- **`pytest.ini` + 8 test files** match the playbook contract exactly.
