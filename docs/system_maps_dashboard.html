Beginner Onboarding Flow

Step 1Run the troubleshooter first.
Step 2If the platform is down, run the startup script.
Step 3Run the smoke test to prove the live stack works.
Step 4If you need latest main, wait for upstream ready, safe sync, then revalidate.
Step 5Push through git-menu.ps1 on your own branch.
flowchart TD A["Run troubleshooter"] --> B{"Platform healthy?"} B -- No --> C["Run start_platform.ps1"] C --> D["Run smoke test"] B -- Yes --> D D --> E{"Need latest main?"} E -- Yes --> F["Wait for upstream ready"] F --> G["Run safe sync"] G --> H["Run troubleshooter and smoke test again"] E -- No --> I["Continue work"] H --> J["Push via git-menu.ps1"]
